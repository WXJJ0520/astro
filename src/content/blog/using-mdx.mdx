当前这版博客已经启用了 MDX 支持，但我暂时不会滥用它。

原因很简单：**多数技术文章其实 Markdown 就够了**。

只有在下面这些情况，我才会考虑 MDX：

- 文章里需要插交互组件
- 要展示更复杂的图表
- 想做 demo 嵌入

在那之前，保持内容简单、结构清晰，比花哨更重要。
