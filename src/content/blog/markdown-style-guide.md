为了让文章风格统一，后面我会尽量按这个简单模板写：

1. 开头先说问题背景
2. 中间给方案和过程
3. 最后补结论和注意事项

## 标题层级

- 一个页面只有一个一级标题
- 正文从二级标题开始
- 不为了“好看”乱跳层级

## 代码块

尽量带语言标记，例如：

```bash
npm run build
```

## 图片

如果图片只是辅助说明，就少放；如果图片是步骤关键，就放清楚。

博客首先是给人看的，不是给页面堆素材的。
